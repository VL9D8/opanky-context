# Architecture

## Source ownership

This hub owns cross-project public context. Each project repository owns code and runtime truth. External design systems own original assets. Git history owns accepted evidence. Private capture remains separate.

## Boundaries

Private capture -> curated change -> public hub -> owning project repositories. The hub summarizes verified public context; it does not replace source repositories or external asset owners.
