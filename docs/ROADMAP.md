# Roadmap

## Milestone 1

Create the owning Outreach integration ledger, choose its canonical branch/source, and separate private leads. Exit when the ledger and source decision are accepted in the owning `opanky-outreach` repository without exposing private leads.

## Milestone 2

Package Ashie Studio's direct and white-label offers and run the first measurable twenty-day revenue sprint. Exit when `ashie-studio` records the offer package and measured sprint result.

## Milestone 3 — complete 2026-08-10

One bounded owning-repository-to-hub update workflow was proven through [PR #3](https://github.com/VL9D8/opanky-context/pull/3). The owning-repository evidence opened a reviewable context pull request, required `context`, `links`, and `secrets` checks passed, and no private data was published. No broader synchronization automation or speculative backlog is maintained here.

## Milestone 4

Review the first three manual Content Engine runs and record explicit approve, edit, or reject outcomes. Exit when every selected draft has an owner outcome and the evidence shows whether the manual workflow is useful; automatic publication and scheduling remain out of scope.
