# OPANKY Context

This repository is the public, AI-readable registry for the OPANKY ecosystem. It is not the execution control plane and not a code monorepo.

## Start here

Read [CONTEXT.md](CONTEXT.md), then the relevant canonical document and its owning project source. Machine readers start at [llms.txt](llms.txt), then [context.json](context.json). Core references: [Current State](docs/CURRENT_STATE.md), generated [Projects](docs/PROJECTS.md), generated [Portfolio](docs/PORTFOLIO.md), and [Decisions](docs/DECISIONS.md).

## Freshness

Treat `last_verified_at` as the freshness boundary. A claim without current evidence is Partial, Unknown, or Not published; do not infer it.

## Public boundary

Public context excludes secrets, contacts, raw chats, private paths, confidential briefs, unpublished assets, and unapproved source URLs. Owning project repositories remain authoritative for code and runtime truth.
